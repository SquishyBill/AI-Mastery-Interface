# Threat Scanner

A 15-minute activity that teaches teachers and students how to evaluate the privacy and security of AI tools before trusting them with real use.

**What it does**

- **Scan:** practice spotting risky and missing language in sample AI-tool policies, using three lenses: Data, Rules and Sight.
- **Adaptive ladder:** everyone starts at a Standard level. The activity recommends an easier or harder scenario based on results, with achievement badges. There is no timer and no leaderboard.
- **Field test:** apply the same method to a real tool. Choose Manual, the in-browser Policy Analyzer, or Quick Profiles (notes on a few popular tools).
- **Clearance Card:** a one-page result with a verdict and next steps.
- **Operator guide:** a run of show and discussion questions for facilitators.

**Privacy**

Everything runs in the browser. No data is sent anywhere by the activity itself. The Policy Analyzer matches phrases in pasted text locally and does not use AI. Pilot feedback is only collected if a person chooses to copy their summary and paste it into the feedback form.

The page loads fonts from Google Fonts. If your school blocks that, the page falls back to system fonts.

**Important**

This is a teaching activity, not legal advice. Results are exercise results, not district approval. Tool notes in Quick Profiles were gathered from public pages in October 2026 and can go out of date. Always confirm with your district's technology office.

## Files

- `index.html`: the whole activity in one file (no build step, no dependencies).

## Publish with GitHub Pages

1. Create a new public repository on GitHub (for example `threat-scanner`).
2. Upload `index.html` and this `README.md` (Add file, then Upload files, then Commit).
3. Open the repository's Settings, then Pages. Under "Build and deployment," choose "Deploy from a branch," pick `main` and `/ (root)`, and save.
4. After a minute the site is live at `https://YOUR-USERNAME.github.io/threat-scanner/`.

To update the activity later, upload a new `index.html` to the same repository.
